# Samarth College of Nursing — Swami Samarth V Om Gagangiri Foundation

Official website and digital portal for **Samarth College of Nursing, Sangamner (Ahilyanagar)**, run by **Swami Samarth V Om Gagangiri Foundation**.

Recognized by the **Government of Maharashtra** and affiliated with **MSBTE Mumbai**.

---

## 🌟 Academic Programs Offered

* **GNM (General Nursing & Midwifery)** — 3 Years Diploma (Established 2024)
* **ANM (Auxiliary Nursing & Midwifery)** — 2 Years Diploma (Established 2024)
* **ADMLT / PGDMLT (Advanced Diploma in Medical Laboratory Technician)** — 1.5 Years (Established 2021)

---

## 🚀 Key Features

* **Dual Language Support (EN / मराठी)**: Instant one-click toggle across the entire website including all inner pages, navigation, footer, and leadership messages.
* **Modern Ultra-Responsive UI**: Clean typography, glassmorphism headers, hero carousel, interactive lightboxes, and smooth scroll animations.
* **Leadership Desks**: Dedicated messages and verified credentials for GNM and ANM principals.
* **Campus & Facilities**: Comprehensive details on student hostel accommodation (10 highlights) and Government scholarship assistance (MahaDBT guidance).
* **Admissions & Enquiry Desk**: Direct inquiry submission form connected to PostgreSQL database.

---

## 🛠️ Technology Stack

* **Framework**: Next.js 14 (App Router)
* **Frontend Library**: React 18
* **Styling**: Modular Vanilla CSS with responsive grid and flexbox
* **Database ORM**: Prisma ORM
* **Database**: PostgreSQL
* **Deployment**: Vercel

---

## 💻 Getting Started

```bash
# Install dependencies
npm install

# Run database generation
npm run postinstall

# Run local development server
npm run dev

# Build for production
npm run build
```
